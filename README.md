# End-to-End Customer Churn Analysis & Prediction | Python, SQL, Machine Learning & Power BI Dashboard

## Project Overview 
This project presents an end-to-end Customer Churn Analysis and Prediction solution for a telecom company. 

## Objective
The objective is to identify customer churn patterns, uncover key business drivers, estimate revenue at risk, and predict future churn using machine learning.

## Business Problem 

A telecom company is losing customers.

Management wants to know:
1. Which customers are leaving?
2. Why are they leaving?
3. Which customer segments are at risk?
4. How much revenue is at risk?
5. Can we predict future churn?

## Technology Stack
The project combines Data Cleaning, Exploratory Data Analysis (EDA), Statistical Testing, SQL-Based Business Analysis, Predictive Modeling, and Interactive Power BI Dashboards to deliver actionable business insights.

## Key Features:
- Data Validation and Quality Assessment
- Exploratory Data Analysis (EDA)
- Statistical Significance Testing using Chi-Square Analysis
- SQL-Based KPI and Customer Segmentation Analysis
- Logistic Regression Churn Prediction Model
- Customer Risk Segmentation (High, Medium, Low Risk)
- Revenue at Risk Analysis
- Interactive Power BI Dashboard for Executive Reporting

## Tools & Technologies:
- Python (Pandas, NumPy, Scikit-Learn)
- MySQL
- Power BI
- Statistics
- Machine Learning
- GitHub

## Model Performance:
- Accuracy: 80.38%
- Precision: 64.76%
- Recall: 57.49%
- F1 Score: 60.91%
- ROC-AUC: 83.57%

## Key Business Insights:
- Month-to-Month customers are the most vulnerable segment.
- Electronic Check users exhibit the highest churn behavior.
- New customers (0–12 months tenure) show significantly higher churn rates.
- High-value customers contribute substantially to revenue at risk.
- Customer tenure, contract type, and internet service are among the strongest predictors of churn.

## Business Recommendations

### Recommendation 1: Retention Campaign
Target high-risk customers with churn probability above 70%.

### Recommendation 2: Contract Conversion
Move Month-to-Month customers into annual plans through discounts and loyalty benefits.

### Recommendation 3: Customer Onboarding
Improve first-year customer engagement because the 0–12 month segment has the highest churn rate.

### Recommendation 4: Payment Method Optimization
Improve first-year customer engagement because the 0–12 month segment has the highest churn rate.
